# daber-a3cha# دَبّر عشانا (Daber A3cha) 🍳

مشروع متواضع يساعدك في اختيار وتدبير وجبة العشاء بسهولة وبأقل المكونات المتاحة لديك.

## 🌟 الميزات (Features)
- **اقتراح أكلات:** إعطاء اقتراحات وسريعة لوجبة العشاء.
- **بحث بالمكونات:** إدخال المكونات المتوفرة في ثلاجتك واقتراح الوصفة المناسبة.
- **وصفات سهلة وسريعة:** تحضير في أقل من 30 دقيقة.

## 🛠️ التقنيات المستخدمة (Tech Stack)
- HTML5 / CSS3 / JavaScript
- Python / Node.js (حسب التقنية التي ستستخدمها)

## 🚀 كيفية التشغيل (How to run)
1. قم بتحميل الملفات أو عمل `git clone`.
2. افتح ملف `index.html` في المتصفح.
